 Cumplimiento de Requisitos de la Práctica

                
                

                  
1. Cifrado Simétrico aplicado a datos de la aplicación

                  
    
                    
  • Algoritmo implementado: AES-256-GCM (Advanced Encryption Standard con Galois/Counter Mode).
    • 
                    
  • Librería: node:crypto (librería criptográfica estándar y nativa de Node.js basada en OpenSSL 3).
    • 
                    
  • Almacenamiento de Llave: Variable de entorno CRYPTO_AES_KEY en el archivo .env (clave de 256 bits en hexadecimal). No está hardcodeada en el código fuente.
    • 
                    
  • Flujo completo demostrado: El texto sensible entra en claro por formulario/API, se cifra con un IV aleatorio de 12 bytes y Auth Tag de 16 bytes, se guarda cifrado en formato iv:authTag:ciphertext, y se descifra para usuarios con permiso.
    • 
                  

                


                

                  
2. Cifrado / Firma Asimétrica aplicada a una función

                  
    
                    
  • Algoritmo implementado: RSA-SHA256 (Longitud de clave de 2048 bits).
    • 
                    
  • Librería: node:crypto (módulo nativo).
    • 
                    
  • Almacenamiento de Llaves:
                      
      
                        
    • Llave Privada: Archivo protegido certs/portal-private.pem con permisos de solo lectura para el proceso del servidor (ruta en PORTAL_PRIVATE_KEY_PATH).
      • 
                        
    • Llave Pública: Archivo certs/portal-public.pem accesible públicamente vía API /api/crypto/public-key para verificación ciudadana (ruta en PORTAL_PUBLIC_KEY_PATH).
      • 
                      
    
                    
    • 
                    
  • Caso Real: Firma digital y sello de autenticidad e integridad de noticias y comunicados periodísticos. Permite detectar de inmediato si un registro de la base de datos fue manipulado por un tercero.
